# About this journal

This journal follows <a href="{{ site.repository }}">{{ site.repositoryName }}</a>: the problems being worked on, the decisions behind them, and what happens when designs meet implementation.

This is an independent journal, not an official project publication or a replacement for release notes.

## One checkpoint, one entry

Each poll compares the repository with the last reviewed checkpoint. We read changed proposals, implementation work and discussion, then write the developments as connected engineering stories. Collection scope and any additional source checks are stated in each entry; this is not a claim to have reviewed every commit.

A new poll produces a new dated article at a permanent URL. Older entries remain available in the archive. Their dates and observation windows matter: a PR described as open in an older article may have merged since then.

## Evidence before interpretation

A proposal is not a delivered feature. A merged design is not a merged implementation. An author's successful test is useful evidence, not the same as an independent deployment test. Entries keep those distinctions visible and link to primary sources.

When we see a pattern across changes, we describe it as an interpretation—not an official roadmap or a claim about someone's private intentions.

## A consistent editorial format

Articles explain the previous limitation, the change, its practical effect and remaining work. Continuing stories link back to earlier entries. Corrections are dated and described; we do not silently rewrite past observations to match the present.

The illustrations are original AI-generated editorial artwork. They are visual metaphors, not architectural evidence. Precise technical diagrams, where needed, are separately labelled.

## Built to stay simple

The site is static HTML, generated by [Eleventy](https://www.11ty.dev/) from Markdown posts and shared templates. There is no account system, database, analytics or browser-side application. The same templates, typography and illustration direction are used for every entry.
